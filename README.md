# DineDecide

A Python Restaurant Decision Helper

# Project Overview

DineDecide is a text-based Python program that helps users choose a restaurant in Sydney.

I created this project because I sometimes find it difficult to choose from restaurants I have never visited. DineDecide uses information from 159 restaurants in Sydney and recommends one restaurant based on the user's choices.

# Features

Choose a cuisine from the available list.

Choose a location that offers that cuisine.

Set a minimum Chef Hat rating. The program automatically selects the rating when only one is available.

If no restaurant meets the minimum rating, enter a lower rating.

Get a random restaurant recommendation with its Chef Hat rating.

Get another recommendation without repeating previously recommended restaurants.

Choose another cuisine or quit after a recommendation.

Type "quit" when selecting a cuisine or location.

Try again after entering an invalid cuisine or location. 

# Requirements

Python 3

IDLE

My program uses the built-in random module of Python, and no additional Python libraries need to be installed. The restaurant data has been stored in the Python file.

# How to Open and Run

1. Download DineDecide.py from this GitHub repository.

2. Open IDLE.

3. Select File.

4. Click Open and open DineDecide.py.

5. Select Run.

6. Click Run Module or press F5.

7. Follow the instructions in the Python Shell.

# How to Use

1. View the cuisine list and enter a cuisine.

2. Choose one of the available locations.

3. If the program asks you to input a minimum Chef Hat rating, enter a number from the displayed ratings. Restaurants with that rating or higher can be recommended.

4. Read the restaurant name and Chef Hat ratings that DineDecide recommends.

5. Select the next step:

   option 1: Recommend another restaurant (when more matching restaurants are available).

   option 2: Choose another cuisine.

   option 3: Quit.

7. You can type quit at the cuisine or location step. Once all matching restaurants have been recommended, the program only provides options 2 and 3.
